--- title: Graft - One git worktree per task date: 2026-08-26 tags: - ai - claude - git - bash ---

Graft is my take on a better git worktree integration for Claude Code. Claude Code's built-in worktree support works well, and it was the inspiration for this, so kudos to the team for building it. Graft adds a few things that solve problems I kept hitting on my own projects, especially monorepos and juggling several projects at once.

Names are never reused, so continuing a conversation can't resume some other task's chat. It can start the session in a subfolder, so a monorepo app's CLAUDE.md and skills are actually found. It copies gitignored files like .env and .mcp.json into every worktree with no setup. graft --list shows what's running, what's unlanded and what each worktree is for; any unique part of a name reopens one; and cleanup is only offered once the work has landed. It's a single bash script, licensed under the AGPL.
